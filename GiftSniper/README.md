# Gift Sniper — снайпер подарков/NFT Telegram + сравнение цен по маркетам

Бот следит за новыми лотами подарков на **Portals**, **MRKT**, **Tonnel** и **официальном маркете Telegram**,
сравнивает цену каждого лота с флорами (той же модели или коллекции) на всех маркетах и присылает
алерт, если купленный подарок можно перепродать **в окуп** с учётом комиссий и стоимости переводов.

## Что умеет

- 🎯 **Снайпер.** Опрашивает свежие лоты каждые N секунд и сравнивает каждый новый лот (или лот с новой ценой)
  с флором той же модели на всех маркетах. Сам лот в расчёт флора не входит.
- 📊 **Арбитраж по флорам** (`/arb`): по каждой коллекции считает «купить по флору на A → продать по флору на B»
  и показывает топ расхождений, уже за вычетом комиссий.
- 🔎 **Где купить и где продать** (`/floor Plush Pepe | Gold`): цены на всех маркетах, где дешевле купить,
  где выгоднее продать, сколько останется на руках и окупается ли сделка.
- 🛒 **Покупка.** Под каждым алертом есть кнопка «Купить» (с подтверждением). Автопокупку можно включить:
  она ограничена лимитом цены, дневным бюджетом, числом покупок в час, порогами профита и включается отдельно
  для каждого маркета. По умолчанию стоит **dry-run**: бот только пишет «купил бы» и ничего не тратит.
  Это касается и кнопки «Купить». Для реальных покупок поставьте `autobuy.dry_run: false`.
- 📣 **Дайджест в канал**: топ арбитражных расхождений по расписанию или по команде `/digest`.

## Как считается окупаемость

```
цена_продажи = флор_на_маркете_B × (1 − undercut)              # чуть ниже флора, чтобы ушло быстро
на_руки      = цена_продажи × доля_продавца_B                  # минус комиссия маркета (и наценка Tonnel)
профит       = на_руки − цена_покупки − (вывод с A + ввод на B) # перевод не нужен, если A = B
ROI          = профит / (цена_покупки + переводы)
```

- Все цены приводятся к TON. Цены в Stars пересчитываются по курсу покупки (`star_buy_usd`),
  выручка в Stars — по курсу вывода (`star_sell_usd`).
- Tonnel отдаёт цену продавца, а покупатель платит примерно на 10% больше. Бот это учитывает (`price_markup`).
- Долю продавца на маркете Telegram бот пытается взять из app config Telegram, иначе использует значение из конфига.

> ⚠️ **Комиссии в `config.example.yaml` примерные.** Маркеты их меняют, поэтому перед реальными покупками сверьте
> `sell_fee`, `price_markup`, `deposit_cost_ton` и `withdraw_cost_ton` с тем, что показывают сами маркеты.

## Запуск прямо на Android-телефоне (Termux)

Бот работает, пока телефон включён, есть интернет и Termux не закрыт. На iPhone так не получится.

1. Установите **Termux** из F-Droid (https://f-droid.org/packages/com.termux/). Версия из Google Play устарела.
2. Создайте бота в @BotFather и скопируйте токен.
3. Откройте Termux и вставьте одну команду:
   ```
   curl -sL https://raw.githubusercontent.com/pravorov333-pixel/lume-client-/ccr-ac390c81-vj2x5m/GiftSniper/termux/install.sh | bash
   ```
   Установка займёт 5–15 минут. В конце скрипт попросит токен бота.
4. Запуск: `gs`. Обновить код: `gs update`. Сменить токен: `gs token`.
5. В Telegram: `/start` → `/api <api_id> <api_hash>` → `/login` (подробно — в разделе ниже, шаг 4).

Чтобы Android не усыплял бота: в настройках телефона отключите для Termux оптимизацию батареи.
Команда `gs` сама включает `termux-wake-lock`.

## Запуск с телефона (без компьютера)

Боту нужен сервер, который работает круглосуточно. Проще всего — [Railway](https://railway.com): там всё делается из браузера телефона.

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте токен.
2. **Ключи API.** Откройте https://my.telegram.org → войдите по номеру → *API development tools* →
   создайте приложение (название любое) → запомните `api_id` и `api_hash`.
3. **Сервер.** railway.com → *Login with GitHub* → *New Project* → *Deploy from GitHub repo* →
   выберите этот репозиторий. Затем в настройках сервиса:
   - *Settings → Source → Root Directory*: `GiftSniper` (и нужную ветку);
   - *Variables*: `BOT_TOKEN` = токен из шага 1;
   - *Volumes*: добавьте том и смонтируйте в `/data` (там хранятся вход в аккаунт и настройки).
   Railway сам соберёт `Dockerfile` и запустит бота.
4. **В боте:** `/start` (первый, кто написал, становится владельцем) → `/api <api_id> <api_hash>` →
   `/login` → кнопка «Отправить мой номер» → код из Telegram **через пробелы** (`1 2 3 4 5`) →
   облачный пароль, если он есть. После этого бот подключит маркеты и начнёт присылать находки.
5. Настройки меняются командой `/set` (список — `/settings`), например
   `/set min_profit 1`, `/set channel @mychannel`, `/set digest 60`, `/set dry_run off`.

Подойдёт и любой VPS с Docker: `docker build -t giftsniper . && docker run -d -e BOT_TOKEN=... -v gs:/data giftsniper`.

## Установка на компьютере

```bash
cd GiftSniper
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.yaml config.yaml                     # заполнить api_id, api_hash, bot_token, admin_ids
python -m giftsniper login                             # или войти потом через /login в боте
```

- `api_id` и `api_hash` берутся на https://my.telegram.org. Аккаунт нужен, чтобы открывать мини-аппы маркетов
  (из них берётся initData для API) и работать с маркетом Telegram.
- `bot_token` выдаёт @BotFather. В `admin_ids` укажите свой user id: остальным бот не отвечает.
- Секреты можно передать через переменные окружения: `TG_API_ID`, `TG_API_HASH`, `BOT_TOKEN`,
  `PORTALS_INIT_DATA`, `MRKT_INIT_DATA`, `TONNEL_INIT_DATA`, `GIFTSNIPER_PROXY`.

## Запуск

```bash
python -m giftsniper run                           # снайпер + бот
python -m giftsniper scan                          # снайпер в консоли, без бота
python -m giftsniper arb --top 20                  # разовая таблица арбитража
python -m giftsniper floor "Plush Pepe" --model Gold
```

Команды бота: `/menu`, `/floor`, `/arb`, `/snipe on|off`, `/autobuy on|off`, `/settings`, `/set`, `/finds`,
`/status`, `/digest`, `/login`, `/logout`.

## Структура

```
giftsniper/
  markets/portals.py   Portals   — portals-market.com/api, Authorization: tma <initData>
  markets/mrkt.py      MRKT      — api.tgmrkt.io, токен через /auth
  markets/tonnel.py    Tonnel    — gifts2.tonnel.network, initData в теле запроса
  markets/telegram.py  Telegram  — MTProto: getResaleStarGifts / getPaymentForm / sendStarsForm
  arbitrage.py         математика профита и арбитража (покрыта тестами)
  engine.py            опрос маркетов, оценка лотов, лимиты автобая
  bot.py               aiogram-бот: алерты, команды, кнопка «Купить», дайджест
tests/                 pytest
```

Новый маркет (например, Getgems) добавляется так: создайте класс-наследник `Market` с методами `latest`,
`floors`, `cheapest` и (по желанию) `buy`, затем пропишите его в `markets/__init__.py` и `MARKET_DEFAULTS`.

## Важно знать

- **API маркетов неофициальные**: эндпоинты взяты из того, как работают их веб-клиенты, и могут поменяться
  без предупреждения. Если маркет сломается, это будет видно в `/status`. Остальные маркеты продолжат работать.
- **Риски.** Флор показывает цену, по которой подарок выставлен, а не цену, по которой его точно купят.
  Тонкий стакан, холд на перевод после покупки и движение рынка могут съесть профит. Начинайте с dry-run
  и маленьких лимитов.
- **Аккаунт.** Слишком частые запросы к Telegram вызывают FloodWait, поэтому маркет Telegram опрашивается
  по кругу и понемногу (`watch`, `collections_per_cycle`). Автоматизация может нарушать правила
  отдельных маркетов: решение и ответственность за ним остаются за вами.
- База (`giftsniper.db` / том `/data`) хранит сессию вашего Telegram-аккаунта — это полный доступ к нему.
  Не давайте никому доступ к серверу и токену бота. Бот отвечает только владельцу.
